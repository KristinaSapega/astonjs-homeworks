Перечислить какие бывают алгоритмы сортировок?

Простые сортировки

1. Пузырьковая сортировка (Bubble Sort)
Сравниваются соседние элементы и меняются местами, если порядок неправильный.
Подходит для обучения, но медленный на больших данных (O(n²)).

2. Сортировка вставками (Insertion Sort)
Элементы вставляются на правильные места в уже отсортированную часть массива.
Эффективен для почти отсортированных массивов (O(n²)).

3. Сортировка выбором (Selection Sort)
На каждой итерации выбирается минимальный элемент из неотсортированной части и меняется местами с текущим.
Низкая производительность (O(n²)).

Быстрые сортировки

4. Быстрая сортировка (Quick Sort)
Выбирается опорный элемент (pivot), а массив делится на элементы меньше и больше pivot.
Рекурсивно сортируются обе части.
Среднее время выполнения: O(n log n).

Pivot (опорный элемент) — это ключевой элемент, выбираемый в некоторых алгоритмах, 
чтобы разделить набор данных на части. 
В контексте сортировки, pivot используется для организации данных относительно него.
Pivot — это элемент, вокруг которого происходит разделение массива на две части:
Элементы меньше pivot размещаются слева от него.
Элементы больше pivot размещаются справа.

5. Сортировка слиянием (Merge Sort)
Рекурсивно делит массив на части, пока каждая не станет из одного элемента.
Затем сливает отсортированные части.
Всегда O(n log n).

6. Пирамидальная сортировка (Heap Sort)
Использует структуру данных "куча" для формирования отсортированного массива.
Время выполнения: O(n log n).

Специфические сортировки

7. Сортировка подсчётом (Counting Sort)
использует частотный подсчёт элементов массива. 
Вместо сравнения элементов (как в Quick Sort или Merge Sort), 
Counting Sort работает только с целыми числами и предполагает, что элементы массива имеют ограниченный диапазон значений.
Инициализация:
Создаётся вспомогательный массив count, где индекс соответствует значению из входного массива, 
а значение в массиве count — количеству раз, которое это значение встречается.

Подсчёт элементов:
Для каждого элемента исходного массива увеличивается соответствующий индекс во вспомогательном массиве count.

Модификация массива count:
Если требуется отсортировать массив, восстанавливается порядок, добавляя к каждому элементу в count сумму всех предыдущих.
Формирование отсортированного массива:

Используется массив count, чтобы размещать элементы исходного массива в правильном порядке.
Эффективен для массивов с ограниченным диапазоном чисел.
Время выполнения: O(n + k), где k — максимальное значение.

8. Поразрядная сортировка (Radix Sort)
Сортирует числа по разрядам, начиная с младших.
Часто использует Counting Sort в качестве вспомогательной.

9. Сортировка методом "ведёрок" (Bucket Sort)
Распределяет элементы по группам (ведёркам), сортирует каждое из них, а затем объединяет.
То есть, 
Разделяет элементы массива на несколько групп (ведёрки), основываясь на диапазоне значений.
Помещает каждый элемент в соответствующую ведёрку.
Отсортировывает элементы внутри каждой ведёрки (обычно с помощью другого простого алгоритма, например, Insertion Sort).
объединяет все отсортированные ведёрки в один итоговый массив.

Эффективен для равномерно распределённых данных.

Встроенные методы сортировки в JavaScript

Array.prototype.sort()
В современных реализациях используется комбинация QuickSort и Insertion Sort для небольших массивов, 
что обеспечивает среднюю сложность O(n log n).

Сортирует массив "на месте" (in-place), т.е. sort() изменяет исходный массив.
По умолчанию сортирует строки в лексикографическом порядке (способ сортировки элементов, который основан на порядке символов, как они следуют в словаре или алфавите), 
но для чисел нужно указывать компаратор.

(Компаратор — это функция, которая определяет порядок элементов в массиве при использовании метода Array.prototype.sort() в JavaScript. 
Она задаёт правила для сравнения двух элементов и возвращает одно из трёх значений:
- Отрицательное число — если первый элемент должен идти раньше второго.
- Ноль — если порядок элементов не меняется.
- Положительное число — если первый элемент должен идти позже второго.)
